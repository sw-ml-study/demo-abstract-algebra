Abstract algebra, visually

Magmas to groups, built and broken in sw-MLPL.

A finite binary operation on n elements is an n × n array. So building one is a single table(f, elements, elements); every law is an array predicate with no explicit loop; every counterexample is an index into that array; and the array is directly renderable.
