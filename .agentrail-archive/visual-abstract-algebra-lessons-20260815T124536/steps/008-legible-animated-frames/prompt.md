The svg(_, "life") animations are unreadable: no row or column labels, every lit cell the same green so a frame cannot say WHICH element it is about, a fixed 0.35s per frame that is far too fast to read, and no caption. For the 5x5 the pattern -- a symmetric hook hinged on the diagonal (the tie at (k,k), two wins along row k, the same two mirrored down column k) sliding down the diagonal -- is invisible. Build u:frames_svg in lib/render.mlpl: the full labelled colour-coded Cayley table drawn underneath at all times, with a per-frame overlay ringing the cells whose result is element k, a caption naming that element, and roughly 1.6s per frame. Use it for the CLI lessons, assets/ and the README. For the web demos, where budget is tight, prefer the STATIC labelled coloured table -- the Latin-square property is visible without any animation once colour carries element identity. Sharpen upstream ask C1/C2 with these exact deficiencies.
