Make the visuals actually viewable. Today the only graphic is an SVG file written to out/ by a CLI script that uses include and write_text -- neither of which the sw-MLPL Web UI supports, so nothing in this repo can be pasted into the browser editor. Deliver: (1) demos/web/*.mlpl standalone web entries whose FINAL VALUE is the SVG string, so the browser REPL renders it inline, with scripts/build-web-demos splicing the lib includes into paste-ready artifacts so there is one source of truth and no drift; (2) animated SVG via SMIL -- the associativity counterexample walked as two markers taking different routes over the Cayley table, which is the payoff of lesson 01; (3) the RPSLS n=5 structure, as both a Cayley table and a dominance digraph on a circle, so there is more than one magma to look at; (4) docs/viewing.md explaining every way to see a visualization: terminal ASCII, out/*.svg in a browser, --svg-out, the Web UI paste, and the animated variants. Animated SVG rather than GIF: SMIL is text, so it needs no encoder and no new language capability, and it stays scalable and diffable.
